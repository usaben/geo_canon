Read the median as well as the RMS column: RMS squares the errors, so a
single inverted instance in twenty shows up as roughly 40 degrees and
hides the fact that the rest agree closely.

CAVEAT -- consistency assumes aligned storage
------------------------------------------------------------------------------
Consistency compares frames in each object's OWN stored coordinates,
which only means what it should if the dataset stores every instance
in a common pose.  ShapeNet does.  ModelNet is upright-aligned but
not azimuth-aligned, and these classes are affected:

    laptop: stored azimuth varies between instances, so the
            consistency figure below includes that spread and
            overstates the rule's error.
